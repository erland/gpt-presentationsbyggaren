# Presentationsbyggaren

Presentationsbyggaren är ett GPT-projekt för att skapa och förbättra professionella presentationer från idé eller källmaterial till redigerbar PowerPoint.

Kärnflödet ska utvecklas mot **brief → storyline → storyboard → stil/design → presentation → kvalitetsgranskning**.

## Status

Steg 1–9 är genomförda. Canonical metod, brief/storyline, stil- och patternbibliotek, storyboard, käll-/verktygspolicy, PPTX-genereringskontrakt, kvalitets-/transformationsflöden och ChatGPT Chat-distribution är definierade och testade. Nästa steg är ChatGPT Custom-distributionen.

## Aktiverade runtimes

- ChatGPT Chat
- ChatGPT Custom

Övriga registrerade runtimes är bedömda men inte aktiverade i v1.
